# Охват карты по регионам

Задача: следить, где на карте мало новостей или нет вовсе, и постепенно добавлять источники (каналы в `channels.txt`, ленты в `feeds.txt`). Не всё сразу: по несколько каналов за раз и только проверенные.

Как смотреть: после каждого запуска «Обновление карты» на странице запуска (Actions → запуск → Summary) есть блок «Охват карты по регионам»: регионы без новостей, с малым числом новостей и без своего источника. Локально: `python coverage.py`.

## Что известно без базы

Нет своего источника (канала или ленты с регионом по умолчанию), новости идут только из федеральных каналов и лент:
Адыгея, Алтайский край, Республика Алтай, Архангельская обл., Астраханская обл., Башкортостан, Белгородская обл., Брянская обл., Владимирская обл., Вологодская обл., ЕАО, Ивановская обл., Ингушетия, Кабардино-Балкария, Калининградская обл., Калмыкия, Калужская обл., Карачаево-Черкесия, Карелия, Кемеровская обл., Кировская обл., Коми, Костромская обл., Курганская обл., Курская обл., Липецкая обл., Магаданская обл., Марий Эл, Мордовия, Московская обл., Ненецкий АО, Новгородская обл., Омская обл., Оренбургская обл., Орловская обл., Пензенская обл., Псковская обл., Ростовская обл., Северная Осетия, Смоленская обл., Ставропольский край, Тамбовская обл., Тверская обл., Томская обл., Тульская обл., Тыва, Тюменская обл., Удмуртия, Ульяновская обл., ХМАО, Хакасия, Чечня, Чувашия, Чукотка, ЯНАО.

## Порядок работы

1. Открыть Summary последнего запуска, взять список «нет новостей» и «мало».
2. Для 3–5 регионов из списка найти открытые каналы ЧП/ДТП/новостей, проверить что `t.me/s/<имя>` отдаёт записи.
3. Добавить в `channels.txt` с местом по умолчанию, проверить следующий запуск (строка «Добавлено» в логе).
4. Отметить здесь, что добавлено.
